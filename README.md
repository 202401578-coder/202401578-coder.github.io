# 이원경 개인 홈페이지

한국외국어대학교 기술개발연구프로젝트 수업에서 만든 개인 소개 홈페이지입니다.
소개, 관심 분야, 학력, 경력, 프로젝트, 대외활동을 한 페이지에 정리했습니다.

## 공개 주소

https://202401578-coder.github.io/

## 파일 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 홈페이지의 내용과 구조 |
| `style.css` | 색상·크기·배치 |

설치나 빌드 명령이 없는 정적 페이지입니다. `index.html`을 브라우저로 열면 그대로 확인할 수 있습니다.

## 배포 방법

GitHub Pages · `main` 브랜치의 `/(root)` 폴더를 게시합니다.
`main`에 Push하면 자동으로 다시 배포됩니다.
