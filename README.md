# 이원경의 홈페이지

## 1. 목적

수업 동료와 연구·프로젝트에 관심 있는 사람에게 나의 학력·경력·프로젝트·대외활동을 보여 주는 개인 홈페이지입니다.
방문자가 내가 어떤 분야를 다루고 있고 각 활동이 언제 이루어졌는지 한 페이지에서 확인할 수 있도록 구성했습니다.

## 2. 주소

- 공개 홈페이지: https://202401578-coder.github.io/ [접속 확인]
- GitHub 저장소: https://github.com/202401578-coder/202401578-coder.github.io
- 외대 학생 서비스: https://202401578-coder.github.io/team-tool.html [제작 전]

## 3. 실행·수정 방법

- 파일: `index.html` [홈페이지], `style.css` [색상·간격·배치]
- 로컬 확인: Clone 폴더의 `index.html`을 브라우저에서 연다.
- 팀 작업: [팀·교차점검팀 미정 / 외대 학생의 상황·핵심 기능 미정 / 내 기여 미정]
- 반영: Stage → `git diff --cached` 확인 → Commit → Push → Pages·공개 URL 확인

설치나 빌드 명령이 없는 정적 페이지입니다. 외부 프레임워크·패키지를 사용하지 않습니다.

## 4. 현재 상태

- 완료: 저장소 생성, 홈페이지 파일 업로드, GitHub Pages 배포(`main` / `/(root)`), 노트북 Clone
- 남은 일: 관심 분야 세 가지에 각각의 이유 문장 추가, 프로젝트의 현재 상태 표기 확정, `team-tool.html` 제작
- 최근 확인: 2026-09-16 / macOS / 공개 URL이 HTTP 200으로 응답하고 `index.html`·`style.css`가 모두 전달되는 것을 확인. 브라우저 화면·좁은 화면(390px)·Tab 이동은 미확인.
- 자료·AI 도움: 홈페이지에 실린 학력·경력·프로젝트·대외활동 내용은 본인이 제공. `index.html`·`style.css` 작성과 Git·Pages 배포 작업은 Claude Code를 사용. 시작 파일은 2주차 수업 제공 `내_홈페이지`.
